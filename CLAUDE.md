# Rules for Claude

## Workflow
- Collect before building: when the owner says "don't build anything yet" / "just collect" ("noch nichts bauen",
  "erst sammeln"), this applies to ALL following instructions until he explicitly says "implement", "build in"
  or "build" ("umsetzen", "einbauen", "bauen") – even if a later message sounds like a task. Until then only take
  notes, summarise and ask: no code, no files, no commits. He does not repeat this with every instruction.
- He compiles himself; no builds on GitHub unless he asks.
- Changelog: newest on top, never delete entries, every change with its commit hash. This repository is public:
  descriptions and changelog in English.
