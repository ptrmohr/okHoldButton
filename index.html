okHoldButton HTML

Drücken, halten, loslassen: Die Aktion wird nur nach vollständigem Halten und anschließendem Loslassen bestätigt. Bei vorzeitigem Loslassen passiert nichts.

Interaktive Demo

Bereit. Maus, Touch oder Leertaste verwenden.

So funktioniert's

1. Taste gedrückt halten: Die Füllung wächst.

2. Bei 100 % erscheint JETZT LOSLASSEN.

3. Erst beim Loslassen erfolgt die Bestätigung.

Loslassen vor 100 % oder den Finger wegziehen bricht ab. Enter oder ein kurzer Klick bestätigen nicht.

Einbau in eine Website

<link rel="stylesheet" href="./src/ok-hold-button.css">
<button id="confirm"></button>

<script type="module">
  import { OkHoldButton } from "./src/ok-hold-button.js";

  const hold = new OkHoldButton("#confirm", {
    holdDuration: 5000,  // or 2000
    text: "BESTÄTIGEN",
    onComplete: () => console.log("Confirmed!")
  });
</script>
