okHoldButton HTML

Press, hold, release. An action is confirmed only after the full hold and release. Let go too early, and nothing happens.

Try it yourself

Ready. Use your mouse, touch screen, or Space bar.

How it works

1. Press and hold: the progress fill grows.

2. At 100%, the button says RELEASE TO CONFIRM.

3. The confirmation fires when you release.

Releasing before 100% or moving your pointer away cancels. A short click or Enter key does not confirm.

Use it in your website

<link rel="stylesheet" href="./src/ok-hold-button.css">
<button id="confirm"></button>

<script type="module">
  import { OkHoldButton } from "./src/ok-hold-button.js";

  const hold = new OkHoldButton("#confirm", {
    holdDuration: 5000,  // or 2000
    text: "CONFIRM",
    onComplete: () => console.log("Confirmed!")
  });
</script>
